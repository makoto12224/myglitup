2.5) これをやる“スマホ側”のメリット

写真をパソコンにコピーできるようになると、スマホにも良いことがたくさんあります。

① 容量が空いて軽くなる

写真・動画は容量を大きく使います。パソコンへ移せば空きが増え、アプリの更新や新規撮影がスムーズに。

② 安心のバックアップ

故障・紛失・水没のときも、パソコンにコピーがあれば思い出を守れます。

③ 整理しやすい

大画面でフォルダ分け・名前変更が簡単。スマホ内アルバムのごちゃごちゃ解消。

④ 機種変更がラク

新しいスマホに移したい写真を、パソコンからスムーズに再コピーできます。

⑤ 長期保存に強い

外付けHDD/SSDやクラウドにも二重保存でき、10年単位の保管がしやすくなります。

＋α：家族と共有しやすい

パソコンでまとめて選んで、USBメモリやクラウド経由で家族に渡せます。

まずはコピーのみ：慣れるまでスマホ側の削除はしないでOK。パソコンに写真があることを確認してから整理しましょう。

1) 準備（ケーブル/機器/安全）

まずは種類を確認

  • スマホ：Android か iPhone（機種名もメモ）
  • パソコン：Windows か Mac（新しめ？古め？）
  • PCの差込口：USB-A（四角）か USB-C（細長）
メモ例：「Pixel 7」「iPhone 13」「Windows 11」「MacBook Air(USB-Cのみ)」

ケーブルの見分け方

  • iPhone：Lightning か USB-C（新しめ）
  • Android：USB-C（主流）／Micro‑USB（古め）
  • PC側：USB-A or USB-C（合わなければ変換アダプタ）
  • データ転送対応のケーブルを使う（充電専用は不可）
注意：100円ケーブルは“充電だけ”のことが多いです。
安全のための3カ条
  • 作業前にスマホ/PCのロック解除とバッテリー50%以上を確認
  • ケーブルはまっすぐ優しく抜き差し（斜めに力をかけない）
  • 初回はコピーのみ（移動は慣れてから）

2) パソコンの超基礎（フォルダ/ドラッグ&ドロップ）

フォルダ＝写真の“入れ物”

Windowsはエクスプローラー、MacはFinderでフォルダを開きます。最初に「スマホ写真」などの保存用フォルダを作っておきましょう。

【新しいフォルダ名の例】 2025-09_家族写真 旅行_福岡 スマホ写真_取り込み用

ドラッグ＆ドロップ

ファイル（写真）をつかんで→運んで→離す操作。まずはコピーでOK。写真を選んで保存用フォルダへドラッグします。

Ctrl / ⌘ を押しながらクリックで複数選択。

3) 4通りの手順（Android/iPhone × Windows/Mac）

① Android × Windows（いちばん簡単）
  1. スマホとPCをUSBケーブルでつなぐ
  2. スマホ通知からUSBの用途を開き、「ファイル転送」を選ぶ
  3. PCでエクスプローラー→スマホ名→内部ストレージ→DCIM を開く
  4. 写真を選び、PCの保存用フォルダへドラッグ＆ドロップ
  5. 終わったら右下のハードウェアの安全な取り外しから外す（推奨）
コツ：大量ならフォルダごとコピーするとラク。
② Android × Mac（Android File Transferを使用）
  1. スマホとMacをケーブルで接続（USB-CのみのMacは対応ケーブルを）
  2. スマホで「ファイル転送」を選ぶ
  3. MacでAndroid File Transferを起動（未導入なら公式から入手）
  4. アプリ内で DCIM を開き、写真をFinderの保存フォルダへドラッグ
ヒント：アプリが開かないときはケーブルを抜き差し or 再起動。
③ iPhone × Windows（DCIMからコピー）
  1. iPhoneとPCをケーブルで接続
  2. iPhoneのロックを解除→「このコンピュータを信頼」→信頼
  3. PCでエクスプローラー→Apple iPhone→DCIM を開く
  4. 写真を選んで保存用フォルダへドラッグ＆ドロップ
補足：Windows「フォト」アプリのインポートでもOK。
④ iPhone × Mac（標準アプリで読み込み）
  1. iPhoneとMacを接続→iPhoneのロック解除→信頼
  2. Macのイメージキャプチャを起動（または写真アプリ）
  3. 左のデバイス一覧からiPhoneを選び、取り込みたい写真を選択
  4. 読み込み（またはすべて読み込み）を押して保存
コツ：保存先フォルダを最初に指定しておくと迷わない。

4) うまくいかないとき（トラブル解決）

スマホをPCが認識しない

  • ケーブルがデータ対応か確認（充電専用NG）
  • 別のUSBポート/別ケーブルで試す
  • スマホのロック解除→もう一度接続
  • Android：通知からファイル転送に切替
  • 再起動（スマホ/PC）

写真が見えない/空っぽに見える

  • iPhone：「信頼」を押したか確認、ケーブル抜き差し
  • Android：DCIMの下のCameraなどフォルダを開く
  • Mac：Android File Transferを再起動
  • Windows：フォトアプリのインポートを試す
まずはコピーのみ：慣れないうちはスマホ側の削除はしない（PCに写真があることを確認してから）。

5) 機種ごとの検索のコツ（そのまま入力OK）

Androidの例

Pixel 7 Windows 写真 転送 Xperia 10 Mac 写真 コピー Galaxy S23 Windows DCIM 見つからない

iPhoneの例

iPhone 13 Windows DCIM 開けない iPhone 写真 Mac 取り込み できない iPhone 信頼 コンピュータ 表示されない
コツ：「機種名」＋「PC種類」＋「写真 転送/取り込み/コピー」＋困っている内容（日本語でOK）。

6) 用語集（3分でわかる）

DCIM

カメラ写真が入る標準フォルダ名（スマホ内）。

ドラッグ＆ドロップ

ファイルをつかんで移動→離して置く操作。

インポート

アプリを使って取り込むこと（写真/フォトなど）。

7) 次の一歩（整理/バックアップ）

フォルダでスッキリ

  • 年月やイベント名でフォルダ分け
  • 良い写真だけ「BEST」へコピー
  • 月に一度の整理タイムをカレンダー登録

安心の二重保存

  • 外付けHDD/SSDに丸ごとコピー
  • クラウドにも1セット（容量に余裕があれば）
